整层历史块，F32，28 层共享全局 LRU。预取全部未驻留候选。上一 token 仅限同轮相邻位置。上一层仅限同 token 的前一层，块位置映射到当前层。

同一步需求批量检查，需求块按块编号更新 LRU。未使用预取包括驱逐和运行结束仍未命中。模型只模拟已记录位置的历史块读取，省略 dense prefill、当前块和实际搬运时延。
