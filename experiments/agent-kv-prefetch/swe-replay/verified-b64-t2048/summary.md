所有题来自 Claude Opus 4.6 的同一份已判定通过的 Bash Only 提交。
使用本地 Qwen3 回放，Quest 64–2048，全局 LRU，无单层预取上限。预取假设即时到达，表中变化量为累计模拟读流量。
